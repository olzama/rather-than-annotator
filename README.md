# Rather Than Judgments

Annotation page for a study of "rather than" in NLP papers. Each item is a
sentence from a published paper with one occurrence of "rather than"
highlighted; annotators judge whether the use annoys them.

Labels are saved to a Google Sheet through a Google Apps Script web app.
Pages: `/` (annotation; add `#revision` for the revision set) and
`/strawman/` (straw-man coding). Open a page, enter your name, and continue from any device with the same
name. 
The page is generated by `build_page.py` in the (private) study repository;
do not edit `index.html` by hand.
